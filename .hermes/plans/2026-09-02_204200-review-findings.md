## P0 — must fix (1)

### F-B4-1. `allowBackup="false"` missing in AndroidManifest
- **Path:** `lunasea/android/app/src/main/AndroidManifest.xml:4-10`
- **Finding:** `<application>` does not declare `allowBackup="false"`.
  Default Android value is `true`, so Google Auto Backup and `adb
  backup` include the Hive database — which stores API keys in
  plaintext (Track B4 confirmed: `LunaProfile.sonarrKey`, `Indexer.apiKey`,
  etc. in Hive boxes opened without cipher).
- **Fix applied in this PR:** added `android:allowBackup="false"`.
- **Source:** DeepSeek V4-Pro B4 review (2026-09-02).

## P1 — recommended (9)

### F-A3-1. Lidarr API monolith + path exception
- **Path:** `lunasea/lib/modules/lidarr/core/api/api.dart` (762 LOC, 1 file
  with 14 controllers inlined; `lib/api/lidarr/` does NOT exist).
- **Finding:** Lidarr is the only service whose API lives under
  `lib/modules/lidarr/core/api/` instead of the canonical
  `lib/api/<svc>/{controllers,models,types}/`. Sonarr/Radarr follow the
  canonical pattern; SABnzbd/NZBGet use Retrofit; Lidarr is the outlier
  on both shape and location.
- **Decision (per ADR-0007 below):** document as accepted exception;
  migrate incrementally via strangler (next Lidarr endpoint = new
  controller under `lib/api/lidarr/`, not in the monolith). Do NOT
  migrate in this branch (Sonarr feature in progress, 0 tests = no
  regression coverage).

### F-A4-1. Spec `add-pending-imports-tile` has wrong paths
- **Path:** `docs/specs/add-pending-imports-tile/{tasks,design}.md`
- **Finding:** tasks.md rows 11-15 + design.md lines 43-45 reference
  `lib/api/sonarr/commands/...`, but Sonarr uses `lib/api/sonarr/controllers/`
  (Radarr uses `commands/`; Sonarr doesn't). Also: design.md claim
  "manual import mode not persisted" is false — Radarr already
  persists `MANUAL_IMPORT_DEFAULT_MODE` in Hive.
- **Fix:** reconcile spec to real paths before implementation. (Will
  land in next PR; not done here to keep this PR review-only.)

### F-A4-2. Radarr already implements the "modal" the spec asks for
- **Path:** `lunasea/lib/modules/radarr/routes/manual_import/`,
  `manual_import_details/`, `core/bottom_modal_sheets.dart`,
  `core/dialogs.dart` (RadarrCommandHandlerManualImport).
- **Finding:** the spec asks for a "pending_import_modal" (folder
  picker + mode selector + Confirm). For Radarr, this exact UI already
  exists as 2 routes (`manual_import` + `manual_import_details`) +
  `configureManualImport()` bottom sheet. Reusing saves ~250 LOC.
  For Sonarr, `lib/modules/sonarr/routes/more/route.dart:52-55` has
  the manual import entry commented out — never implemented.
- **Fix:** spec should navigate to existing Radarr routes; create
  Sonarr manual import from scratch (only stub commented).

### F-B1-1. API keys referenced in code (expected, no leak)
- **Path:** `lunasea/lib/api/sonarr/sonarr.dart:28-37`,
  `lunasea/lib/api/sabnzbd/api.dart:28`,
  `lunasea/lib/api/tautulli/tautulli.dart:42`,
  `lunasea/lib/api/nzbget/api.dart`.
- **Finding:** `apiKey` is a constructor parameter to every API factory.
  Not a leak — keys flow from `LunaProfile` (Hive) → factory → HTTP
  header. Listed for completeness; severity lowered to P2.

### F-B3-1. No `network_security_config.xml`; `usesCleartextTraffic="true"`
- **Path:** `lunasea/android/app/src/main/AndroidManifest.xml:6`.
- **Finding:** cleartext HTTP allowed globally for self-hosted Sonarr
  /Radarr etc. Reasonable for the use case (LAN). **No network
  security config** = no domain allowlist. Acceptable for a LAN
  controller app, but worth documenting in CHANGELOG so users know
  what they're shipping.

### F-B5-1. `launchUrl` is unfiltered
- **Path:** `lunasea/lib/extensions/string/links.dart:6,14`
  (uses `launchUrlString`).
- **Finding:** only 2 call sites, both via an extension that takes a
  string from `luna_*` fields (presumably user-entered). No URL
  scheme filtering (could open `intent://`, `tel:`, custom schemes).
  For a controller app opening internal web UIs, low risk.
  Severity P2.

### F-B6-1. Webhooks exist but no HMAC verification
- **Path:** `lunasea/lib/modules/{sonarr,lidarr,tautulli,radarr}/core/webhooks.dart`,
  `lunasea/lib/system/webhooks.dart`.
- **Finding:** 5 webhook handlers, none grep for `HMAC`/`signature`/
  `verify`. If a webhook URL is exposed externally (e.g. via reverse
  proxy with port forwarding), unauthenticated parties can trigger
  Sonarr/Radarr commands. **P1 if webhook URLs are exposed.** Document
  "firewall or LAN-only" requirement.

### F-F3-1. `Semantics` count in `lib/` = 0
- **Path:** all `lunasea/lib/widgets/ui/*.dart`.
- **Finding:** zero uses of `Semantics`, `semanticLabel`,
  `MergeSemantics`, `textScaler`, `textScaleFactor`. Icons-only
  widgets (`LunaIconButton`, `LunaButton.icon`, `LunaFAB`, appbar
  menu/back, drawer settings, banner close) have no accessible
  name. Contrast: blanco sobre accent #4ECCA3 ≈ 2:1 (falla 3:1
  WCAG components). Touch targets <48dp in `banner` (20) and
  `table` body cells (~20). Hardcoded English string `tooltip:
  'Change Profiles'` in `appbar.dart:279` (no `.tr()`).
- **Severity:** P1 (accesibilidad básica).
- **Fix scope (next PR):** add `semanticLabel` field to `LunaIconButton`
  + `LunaFAB`; add `tooltip:` defaults; localize appbar; raise
  contrast; fix banner close touch target.

### F-F3-2. `navigation_bar` lacks tab role
- **Path:** `lunasea/lib/widgets/ui/bottom_bar/navigation_bar.dart`
- **Finding:** uses GNav custom widget; no `Role.tab` semantics,
  no selected/pressed states announced. Screen reader users can't
  tell which tab is active. P1.

## New ADR proposed

### ADR-0007: Lidarr API path exception (strangler migration)

**Status:** proposed.
**Context:** Lidarr's API lives in `lib/modules/lidarr/core/api/api.dart`
(762 LOC monolith), not the canonical `lib/api/<svc>/{controllers,models,types}/`
shape used by Sonarr/Radarr.
**Decision:** accept the exception now; migrate incrementally. Each
new Lidarr endpoint lands at `lib/api/lidarr/controllers/<resource>/`;
existing endpoints move only when touched for other reasons.
**Consequences:** two mental models during transition (strangler).
Deuda acotada y con fecha implícita (próximo feature Lidarr).
**Migration cost when triggered:** ~8-12h (Pro estimate).
